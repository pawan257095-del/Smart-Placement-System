# Smart Placement & Recruitment System

The Smart Placement & Recruitment System is a Java-based application
designed to streamline the campus placement and recruitment process.

The system provides separate functionalities for Students, Recruiters,
and Administrators. Students can manage their profiles, view eligible
job opportunities, apply for jobs, and track application status.
Recruiters can manage company profiles, create and manage job postings,
view applicants, and update application statuses. Administrators can
manage and oversee the placement system.

The application uses MySQL for persistent data storage and JDBC for
database connectivity. Passwords are securely hashed using BCrypt, and
password recovery is supported through OTP-based email verification
using Jakarta Mail and Gmail SMTP.
